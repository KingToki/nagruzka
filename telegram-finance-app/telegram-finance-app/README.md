# Telegram Finance App

Персональний фінансовий дашборд для управління боргами у Telegram Mini App.

## Функціонал

- 💰 Управління доходами (фіксована зарплата + додаткові надходження)
- 🏦 Підтримка різних типів боргів: розстрочки, кредитні картки, приватні позики
- 📊 Аналітика: Avalanche метод, розрахунок обов'язкових платежів
- 📅 Календар платежів
- 🔄 Підтримка двох валют: UAH та USDT
- ☁️ Синхронізація даних через Cloud Storage

## Технології

- React 18 + TypeScript
- Vite
- Telegram WebApp SDK
- IndexedDB для локального сховища
